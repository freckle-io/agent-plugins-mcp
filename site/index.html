Freckle MCP server

Use Freckle from Claude, Codex, Cursor, VS Code or any other AI agent that speaks the Model Context Protocol. Build company and people lists, enrich and score leads, author and run Workflows, import CRM records, watch Signals and sync Ads audiences, all in plain language.

  • Server URL: https://next-api.freckle.io/mcp/full
  • Transport: Streamable HTTP
  • Auth: OAuth. You sign in to Freckle in the browser and pick a Workspace.
  • Who can use it: any member of a Freckle Workspace.

Set up#

Claude Code#

The plugin connects the server and adds Freckle's skills in one step:

/plugin marketplace add freckle-io/agent-plugins-mcp
/plugin install freckle@freckle-mcp-plugins

Then run /mcp, pick freckle and sign in. Server only, without the skills:

claude mcp add --transport http freckle https://next-api.freckle.io/mcp/full

Claude (claude.ai and Claude Desktop)#

  1. Go to Settings → Connectors → Add custom connector.
  2. Name it Freckle, paste https://next-api.freckle.io/mcp/full, then Connect and sign in to Freckle.
  3. Optional: add the skills. Download freckle.zip and freckle-plan.zip and upload each under Settings → Capabilities → Skills.

Codex#

codex plugin marketplace add freckle-io/agent-plugins-mcp

Run /plugins, install Freckle and sign in. Server only:

codex mcp add freckle --url https://next-api.freckle.io/mcp/full

Cursor#

Add to Cursor, or add this to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "freckle": { "url": "https://next-api.freckle.io/mcp/full" }
  }
}

VS Code#

Install in VS Code, or add this to .vscode/mcp.json:

{
  "servers": {
    "freckle": { "type": "http", "url": "https://next-api.freckle.io/mcp/full" }
  }
}

Other clients#

Any client that supports remote (Streamable HTTP) MCP servers with OAuth can connect to https://next-api.freckle.io/mcp/full. For clients that only run local servers, bridge it with npx -y mcp-remote https://next-api.freckle.io/mcp/full.

What you can ask#

  • "Which Workspace am I in and how many credits do I have?"
  • "Preview VPs of Sales at US software companies with 50 to 500 employees. Don't build anything yet."
  • "Make a Workbook from these 20 domains and fill in industry, headcount and HQ country."
  • "Find work emails for everyone in my Webinar attendees Dataset. Run 10 rows first and show me."
  • "Import my HubSpot contacts in the Customers list every morning and enrich new ones."
  • "Watch these accounts for hiring and funding Signals."
  • "Sync the High intent Dataset to a LinkedIn matched audience."

Credits and safety#

  • Approval before spend. The server tells your agent to quote the maximum cost and get your yes before anything spends credits, to run a sample first when a job is over 100 rows, and to get your approval on a plan before it creates, imports, connects or builds anything.
  • Labelled tools. Every tool carries MCP annotations (read-only, destructive, idempotent, open-world) so your client can auto-approve reads and ask before writes. The reference below shows which tools can spend credits.
  • Secrets stay out of chat. API keys for integrations are entered in a Freckle browser form that connections_setup links to, never in tool arguments.
  • One Workspace per session. The session uses the Workspace you picked at sign-in. Ask your agent to switch, and it changes only that session.

Data and privacy#

Freckle sees only what your agent sends to the tools and returns only data from your Workspace and the providers your Workflows call. Customer data is never used to train AI models. Freckle is SOC 2 Type II audited. snapshot_createUpload shares the current session transcript with the Freckle team for debugging or feedback. Its description tells agents to call it only when you ask, and it works only in clients with a local shell (Claude Code, Codex).

See the privacy policy and terms of service. Data requests: privacy@freckle.io. Security: security@freckle.io.

Troubleshooting#

Sign-in loops or the server shows as disconnected. Remove the connection and add it again, or run /mcp in Claude Code and pick Re-authenticate.

My agent is in the wrong Workspace. Ask it to "switch Freckle Workspace"; it lists the Workspaces you belong to and switches this session.

Tools are missing. Check that the URL ends in /mcp/full. Some clients cap the number of tools; turn off tool groups you don't need.

A run spent more than I expected. Ask your agent for "my Freckle credit usage today" to see it itemised in chat, or check usage in the Freckle app.
